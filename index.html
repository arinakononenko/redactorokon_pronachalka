Мои окна

🎨 Оформление большого окна

Шрифт можно дополнительно изменить для каждого текста, поля ввода, списка или карточек слов. Декоративные шрифты загружаются из интернета; без сети используются похожие системные шрифты.

Фон можно загружать с компьютера или по HTTPS.

🎞 Живой фон из iframe

Вставь код <iframe ...></iframe> из своего сервиса для анимированных фонов либо прямую HTTPS-ссылку. Отдельный фоновый слой не мешает перемещать тексты, поля и пользоваться направляющими.

Живой фон ещё не добавлен.

Живой фон показывается под всеми элементами. Его нельзя нажимать или двигать внутри редактора: это позволяет пользоваться текстом, полями и направляющими. Некоторые сайты запрещают вставку своих страниц в iframe.

В этом режиме белый/цветной прямоугольник исчезает полностью. Остаются только твоя фоновая картинка, текст и интерактивные поля. Прозрачные края PNG сохраняются. Рамка окна скрыта, даже если она включена ниже.

Этот бегунок регулирует только цветную заливку, а не картинку. Чтобы оставить одно фото без подложки и рамки, включи «Только фотография» выше.

Мягкое рассеянное свечение окна

Свечение мягко рассеивается за границы окна. Сохраняется и в экспортируемом задании.

Также можно включить предпросмотр и растянуть окно за зелёные маркеры по краям и углам.

✕ Закрытие и проверка

В редакторе крестик можно перетаскивать. В опубликованном iframe он скрывает содержимое самого задания; встроенное окно Genially закрывается своей кнопкой.

Одно окно = один самостоятельный интерактивный блок. При экспорте каждое получает свой уникальный код. Чтобы копировать отдельный iframe каждого задания без загрузки каждого файла, один раз размести редактор по HTTPS. PNG-фото встраиваются внутрь ссылки — при большом числе изображений лучше использовать HTTPS-адреса.

Редактирование окна

Нажми на текст или поле ответа
1000 × 560
Чтобы переместить несколько предметов, выдели их рамкой мышью или удерживай Shift и нажимай на нужные элементы. Затем просто перетащи выделенную группу мышью. Для группы работают обычные кнопки «Дублировать» и «Удалить». Направляющие автоматически помогают выставить ровные края, центры и расстояния; Alt временно отключает притяжение.

Для задания из текста нажми на конкретное окошко — появятся отдельные синие маркеры, которые изменяют только его размер. Нажми на обычные слова — выделится и переместится весь текст вместе с окошками. Нажми на любой элемент — появятся маркеры. У текста угловые маркеры увеличивают и шрифт, боковые — только рамку. Дважды нажми на текст для редактирования прямо на полотне. У полей ответа все маркеры меняют размер. Enter проверяет ответ (пробелы не мешают). В связанной группе ответы можно писать в любом порядке, а в задании «Порядок слов» карточки перемещаются мышью или парными нажатиями.

Вставить окно в Genially

На опубликованном сайте ссылка определяется автоматически. Учителям ничего вводить не нужно: создай окно и скопируй iframe.

Проверяем адрес опубликованного редактора…
Дополнительно: указать другую ссылку вручную

В Genially выдели картинку → Интерактивность → Окно. Внутри всплывающего окна вставь внешний контент (iframe). Закрывающий крестик в iframe скрывает содержимое задания; закрытие самого всплывающего слоя Genially по кнопке HTML ограничено политикой браузера. Используй также штатный крестик Genially.

Создать задание из текста

Вставь свой текст. В местах с вертикальными чертами автоматически появятся поля для ответов. Первое слово среди вариантов считается правильным. Для одной буквы редактор автоматически создаст маленькое окошко. После создания можно нажимать на каждое окошко отдельно и менять его размер, а нажатием на сам текст — выделять весь блок.

Поле для ввода: |снег| → ученик сам пишет ответ.
Выбор варианта: |молоко/малако/малоко| → ученик выбирает из списка.
Можно несколько слов: |красивая берёза| → ответ проверяется после Enter.
